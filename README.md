## ⚡ Getting Started

No build tools, no dependencies — just open and run.

```bash
# Clone the repository
git clone https://github.com/k4rthickx22/Karthick-s-Portfolio.git

# Navigate into the directory
cd Karthick-s-Portfolio

# Open in browser (or use Live Server in VS Code)
start index.html
```

> **Tip:** Use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension for hot-reload during development.

## 🌐 Deployment

### Vercel (Recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project** → Import your repo
3. Leave all settings as default → **Deploy**
4. Done — your portfolio is live! ✅

### GitHub Pages
1. Go to **Settings → Pages**
2. Source: `Deploy from branch` → `main` → `/ (root)`
3. Save — live at `https://<username>.github.io/<repo-name>/`
